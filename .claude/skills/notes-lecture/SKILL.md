# Lecture-заметка

Lecture-заметка — оглавление лекции: материалы + упорядоченный план со ссылками на атомарные заметки. Содержание **не пересказывается**. Формат — в `CLAUDE.md` vault.

## Вход
- курс (тег, напр. `metopt`), номер пары и/или дата лекции;
- окно создания заметок, если оно не совпадает с датой (по умолчанию: от даты лекции до сегодня);
- свободный текст пользователя «чем лекция в этом году отличалась от конспекта» — спросить один раз, если не сказано; ответ «ничем / не знаю» допустим.

## Процесс

1. **Страницы конспекта.**
   ```bash
   python3 tools/roam.py pdfmap <курс>
   ```
   Прочитать страницы пары через Read (`pages`, физические номера; путь к PDF — `roam.toml`). `pdftotext` искажает формулы — для чтения не годится. Выписать упорядоченный план: разделы, определения, теоремы, леммы, примеры, замечания — с номерами из конспекта («опр. 1.1», «теорема 1.2»).

2. **Заметки-кандидаты.**
   ```bash
   python3 tools/roam.py list --tag <курс> --since <YYYYMMDD> --json
   python3 tools/roam.py list --json          # весь vault: понятие могло быть записано раньше или без тега курса
   ```
   Для каждого пункта плана найти заметку по смыслу (заголовок, при сомнении — `show`). Одна заметка может покрывать несколько пунктов, и наоборот.

3. **Таблица соответствия** — показать пользователю:

   | Пункт конспекта | Заметка | Статус |
   |---|---|---|
   | опр. 1.1 выпуклое множество | Выпуклое множество | есть, проверена |
   | конус | — | нет заметки |
   | — | Выпуклость проекции | в заметках, нет в конспекте |

   Статусы: `есть` (+ проверена / к проверке), `stub`, `нет заметки`, `в заметках, нет в конспекте`. Учесть слова пользователя об отличиях: пункт, которого в этом году не было, помечается, а не выкидывается молча.

4. **Черновик** заметки целиком — в чат. Спросить: создавать ли; какие из «нет заметки» завести заглушками. **Стоп, ждать ответа.**

5. **Создание** (после одобрения):
   ```bash
   python3 tools/roam.py new --title "Метопт. Лекция 1: Выпуклые множества и функции" \
       --tags lecture,metopt --date 2026-09-16 --body-file <черновик тела>
   ```
   Тело готовить во временном файле в scratchpad. Одобренные заглушки — `new … --tags metopt,definition,backfill` с телом `backfill`, затем заменить в плане «/нет заметки/» на ссылку.
   ```bash
   python3 tools/roam.py lint <новая заметка>
   git add -A && git commit -m "lecture: <курс> пара N"
   ```
   Затем `python3 tools/roam.py sync`, чтобы новая заметка появилась в org-roam.

## Шаблон тела

```org
* Материалы
- [[file:../optimization_methods-1.pdf][Конспект 2025/26]], Пара 1, стр. 1–3 (в PDF 3–5), разделы 1.1–1.2
- Отличия этого года: …

* План лекции
1. Выпуклые множества
   - [[id:316B5BFA-8B9F-4267-9086-D6593AAB5F9B][Выпуклое множество]] — опр. 1.1
   - [[id:08CF7113-4709-4C4F-A0E7-4A2ED595BD7F][Выпуклость пересечения выпуклых множеств]] — свойство 1
   - Конус — /нет заметки/
2. Выпуклые функции
   - …

* Вне конспекта
- [[id:…][…]] — было на лекции / добавлено для полноты

* Открытые вопросы
- …
```

Правила:
- порядок — по конспекту, с поправкой на слова пользователя;
- описания ссылок — заголовки заметок в именительном падеже (в lecture-заметке это нормально);
- после ссылки — только привязка к конспекту («опр. 1.1», «теорема 1.2, стр. 2») и, максимум, одна строка связки;
- ссылка на PDF — обычная `file:` (без `::страница`: экспортируется в HTML и не требует org-pdftools);
- «Открытые вопросы» — места, где конспект неясен или расходится с заметками (кандидаты для `/notes-audit`), и вопросы к лектору;
- существующую lecture-заметку дополнять тем же порядком: черновик изменений → одобрение → Edit.
