# Anki-карточки

Карточки живут внутри concept-заметки, в конце файла, под `* Anki :noexport:` (формат — `CLAUDE.md` vault). Отправляет их пользователь из Emacs (`C-c n a`).

## Процесс

1. **Набор заметок.** Аргумент — заметка, тег или lecture-заметка (тогда берутся все заметки из её плана). Без аргумента: `python3 tools/roam.py cards` покажет проверенные заметки без карточек.

2. **Гейт.** `python3 tools/roam.py list --json` → у заметки должен быть `status: audited`. `pending` → сначала `/notes-audit` (карточка с ошибкой хуже, чем её отсутствие); `stub` → пропустить. Исключение — только по явной просьбе пользователя.

3. **Существующие карточки.** `python3 tools/roam.py cards <ref> -v`. Не дублировать. Карточки с `ANKI_NOTE_ID` (уже в Anki) не менять и не удалять без явной просьбы.

4. **Черновики.** Прочитать заметку (`context <ref>` — нужны и связанные определения). Составить карточки по рубрике ниже. Каждое поле прогнать через
   ```bash
   printf '%s' '<текст поля>' | python3 tools/roam.py expand --card
   ```
   (раскрывает макросы, `$…$`→`\(…\)`, `<`→`\lt`).

5. **Показать нумерованный список** (сквозная нумерация по всем заметкам):
   ```
   ## Выпуклое множество
   1 [Basic] Выпуклое множество: определение
     Front: Метопт. Когда множество \(C \subset V\) называется выпуклым?
     Back:  Если \(\forall x, y \in C\ \forall \lambda \in [0;1]\): \[ \lambda x + (1-\lambda) y \in C \]
   2 [Cloze] …
   ```
   Ответ пользователя: `взять 1,2,4-6` · `3: <правка>` · `без 5`. **Стоп, ждать ответа.**

6. **Запись.** `guard <ref> --expect-hash …` → Edit: дописать в конец файла (или в конец существующего `* Anki`). Если `* Anki` ещё нет — создать с drawer `:ANKI_DECK:` (дека курса из `roam.toml`). Если в файле есть `* Review`, порядок двух хвостовых заголовков не важен.

7. **Проверка и фиксация.**
   ```bash
   python3 tools/roam.py cards <refs> --check
   git add -A && git commit -m "anki: <заметки/лекция> (+N)"
   python3 tools/roam.py state cards <refs>
   git add -A && git commit -m "anki: state"
   ```
   Сказать пользователю: запустить Anki, открыть каждую заметку → `C-c n a`. После push в файлах появятся `ANKI_NOTE_ID` — их стоит закоммитить (`git commit -am "anki: ids"`).

8. **Устаревшие карточки.** `python3 tools/roam.py cards --stale` — заметки, изменившиеся после генерации. По каждой: сравнить карточки с текущим текстом, предложить точечные правки тем же способом (список → выбор). anki-editor обновит карточку в Anki по `ANKI_NOTE_ID` при следующем push. Удаление — только руками пользователя (`M-x anki-editor-delete-note-at-point`).

## Рубрика карточек

**Общее**
- Одна карточка — один факт. Если ответ — список из трёх пунктов, это три карточки или cloze по пунктам.
- Вопрос однозначен вне заметки: начинать с префикса курса из `roam.toml` («Метопт. …») и называть объекты («Пусть \(f\colon E \to \mathbb{R}\) дифференцируема, \(E\) выпукло…»).
- Без вопросов «да/нет» и «верно ли». Без «перечислите».
- Первое поле уникально в пределах vault (A06).
- Русский язык; обозначения — как в заметке.
- Label карточки (заголовок `**`) — «<Заметка>: <аспект>», в Anki не попадает.

**Определение** → 1–2 карточки
- Basic «термин → определение» (Front: «Что такое … / Когда … называется …?»).
- Если важна символьная запись — Cloze по формуле; если термин легко забыть — обратная «как называется объект, который …».

**Теорема / свойство** → 3–6 карточек
- (а) формулировка: условия → заключение (Basic или Cloze по заключению);
- (б) по карточке на каждое существенное условие: «Зачем в … требуется X? / Что ломается без X?» — только если ответ есть в заметке или очевиден из доказательства; не выдумывать контрпримеры;
- (в) идея доказательства в 1–3 шагах: ключевой приём (сведение к одномерному случаю, индукция по числу точек…), не всё доказательство;
- (г) связь: «из чего следует / где используется», если это видно по ссылкам.

**Заглушки, lecture и hub-заметки** — без карточек.

**Техника**
- Математика только `\(…\)` и `\[…\]`; многострочное — `\[ \begin{aligned} … \end{aligned} \]`, причём `\begin` не в начале строки.
- Макросы раскрыты (`\R` → `\mathbb{R}`); `\lt`, `\gt` вместо `<`, `>`.
- Cloze: `{{c1::…}}`, подсказка `{{c1::…::hint}}`; внутри cloze в формуле не допускать `}}` — писать `} }`. Всегда оба поля: `Text` и `Back Extra` (можно пустое по смыслу, но подзаголовок обязателен — иначе anki-editor положит в него заголовок карточки).
- Без id-ссылок и org-разметки, зависящей от Emacs.

## Формат

```org
* Anki :noexport:
:PROPERTIES:
:ANKI_DECK: Notes::metopt
:END:
** Дифф. критерий выпуклости: неравенство
:PROPERTIES:
:ANKI_NOTE_TYPE: Cloze
:END:
*** Text
Метопт. Если \(f\colon E \to \mathbb{R}\) дифференцируема и выпукла на выпуклом \(E\), то \(\forall x, y \in E\): {{c1::\(f(y) \ge f(x) + \langle \nabla f(x), y-x \rangle\)}}
*** Back Extra
График лежит не ниже касательной гиперплоскости.
```

Имена типов и полей берутся из `roam.toml [anki.*]`. Они **не подтверждены** для профиля пользователя: при первом запуске, если Anki открыт, проверить
```bash
curl -s localhost:8765 -X POST -d '{"action":"modelNamesAndIds","version":6}'
curl -s localhost:8765 -X POST -d '{"action":"modelFieldNames","version":6,"params":{"modelName":"Basic"}}'
```
и при расхождении предложить пользователю поправить `roam.toml`.
