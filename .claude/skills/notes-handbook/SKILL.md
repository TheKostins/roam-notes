# PDF-конспект курса (handbook)

Конспект собирается **из заметок**: `handbook/<курс>/notes/<id>.tex` и `chapters/*.tex` генерирует `roam.py handbook`, ручной слой — `main.tex`, `handbook.toml`, `text/*.tex`, `bilety.tex`. Порядок глав и разделов задают lecture-заметки (`* План лекции`, `* Вне конспекта`); менять порядок = править lecture-заметку по её обычному процессу (черновик → одобрение → Edit с `guard`). Сгенерированные файлы не редактировать никогда: правится заметка или конвертер (`tools/roam_tex.py` + тест).

## Вход
- курс (тег, напр. `metopt`);
- режим: по умолчанию полный (план → сборка → отчёт → применение); `--check` — только план и сборка, отчёт не нужен (быстрая пересборка после правок заметок).

## Процесс

1. **План и предупреждения.**
   ```bash
   python3 tools/roam.py handbook plan <курс>
   ```
   Прочитать главы/разделы/заметки и предупреждения (`X01`–`X14`, расшифровка в docstring `tools/roam_tex.py`). Сверить порядок с конспектом прошлого года (`pdfmap <курс>`, страницы через Read) — расхождения только отметить, конспект не авторитет.

2. **Сборка.**
   ```bash
   python3 tools/roam.py handbook build <курс>
   ```
   Команда сама делает export и печатает только ошибки LaTeX, undefined refs и счётчик overfull. Ошибку разобрать по источнику:
   - в заметке (незакрытая формула, неизвестная команда, `#+begin_src`) — это находка для `/notes-audit`, tex руками не чинить;
   - в конвертере — починить `tools/roam_tex.py`, добавить тест в `tools/test_roam.py`, пересобрать;
   - в стиле (`handbook/common/*.tex`) — править там, это ручные файлы.
   Отладка одной заметки: `python3 tools/roam.py handbook export <курс> --note <ref>`.

3. **Визуальная проверка.** Read `handbook/<курс>/build/main.pdf` с `pages`: титул, оглавление, список утверждений, 1–2 главы, приложение. Смотреть на: обрывы абзацев, потерянные строки, `Rem:` в тексте (не вынесенное замечание), сломанную нумерацию, пустые боксы.

4. **Отчёт в чат** — нумерованный, сплошная нумерация, классы:
   - **O** порядок: заметка вне плана (`X12`), транзитивно добавленный пререквизит, порядок vs конспект — предлагаемая правка lecture-заметки (полный текст пункта);
   - **T** текстовый слой: введение к главе (`text/NN-intro.tex`), связка перед заметкой (`text/<ID>-before.tex`), концовка (`text/NN-outro.tex`) — полный LaTeX-текст в отчёте, 2–6 строк каждый, макросы из `macros.tex` разрешены;
   - **B** билеты: когда есть список вопросов — черновик `bilety.tex` (по образцу `../hse-uberhandbook/probability/bilety-nav.tex`: вопрос → `\cref`/`\hyperref[note:ID]`);
   - **C** конвертер/стиль: что конвертер не понял (`X01`, `X05`, `X09`), предлагаемая правка `roam_tex.py` или `theorems.tex`;
   - **N** находки в заметках, замеченные при чтении PDF — только перечислить и передать в `/notes-audit`, здесь не править.
   Форма ответа: `применить 1,3,5-8` · `всё кроме 4` · `3: <свой вариант>` · `отклонить 2,9`.

   > **После отчёта — стоп. Ждать ответа пользователя.**

5. **Применение** выбранного:
   - T/B — писать `.tex` в `handbook/<курс>/text/` и `bilety.tex` напрямую (не `.org`, правило 1 CLAUDE.md не действует; `guard` не нужен);
   - O — только через lecture-заметку: `guard <ref> --expect-hash …` + Edit, как в `/notes-lecture`;
   - C — код + тест, `python3 -m unittest tools/test_roam.py`;
   - затем снова `handbook build <курс>` и проверка PDF.

6. **Фиксация.**
   ```bash
   git add handbook tools .claude CLAUDE.md
   git commit -m "handbook: <курс> (<N> заметок, глав <M>)"
   ```
   `build/` в `.gitignore`, PDF в git не попадает. В ответе — путь `handbook/<курс>/build/main.pdf` и `--open` для просмотра. Если в рабочем дереве есть чужие изменения `.org` (например, `ANKI_NOTE_ID` после push) — не добавлять их в этот коммит.

## Что где лежит

| Файл | Кто пишет |
|---|---|
| `handbook/common/{prelude,math,theorems}.tex`, `handbook/.latexmkrc` | ручной (стиль) |
| `handbook/common/macros.tex` | генерируется из `my/notes-latex-macros` |
| `handbook/<курс>/main.tex`, `handbook.toml`, `text/*`, `bilety.tex` | ручной (агент по одобрению) |
| `handbook/<курс>/{chapters.tex,chapters/*,notes/*,aux.tex,meta.tex}` | генерируется, полностью |

Окружение заметки по тегу типа: definition → `definition`, theorem → `theorem`, lemma → `lemma`, property → `proposition`, example → `example`, method → `method`; `* Доказательство` → `proof` с `\proofpart`/`\proofstep` по вложенным заголовкам; `* Пример` → `example`; абзац `/Rem/: …` → `remark` после бокса; прочие заголовки → `proposition` + `X01`. `:noexport:` не выводится. Ссылки → `\hyperref[note:<ID>]{…}`, если цель в конспекте, иначе просто текст (`X07`).
