#+title: Алгоритм Backtracking для подбора шага Армихо-Вульфа
#+filetags: :metopt:method:

Алгоритм ищет шаг, который удовлетворяет [[id:15611E05-13FC-4FB0-AE00-A4BB857A29E6][условию Армихо]].

* Алгоритм
#+begin_src python
  # Условные обозначения:
  #   phi(a) = f(x + a*d) - функция по направлению d
  #   dphi(a) = grad_f(x+a*d) @ d - производная по направлению d

  def backtrack(phi, dphi0, alpha0=1.0, c1=1e-4, beta=0.5):
      """Шаг с условием Армихо. dphi0 = phi'(0) < 0, 0 < beta < 1"""
      phi0 = phi(0.0)
      alpha = alpha0
      while phi(alpha) > phi0 + c1 * alpha * dphi0: # Условие армихо нарушено
          alpha *= beta
      return alpha
#+end_src

* Почему алгоритм остановится?
В 1 шаге доказательства теоремы [[id:C143295F-C422-4FEE-95AD-3D6B620BC0E8][Существование шага для Армихо-Вульфа]] мы доказали, что условие Армихо выполнено во всех точках интервала $(0;\delta)$. А так как $\beta^k\alpha_0 \rightarrow 0$, то при достаточно большом $k$, оно окажется в нужном интервале.

* Почему шаг достаточно большой?
Давайте посмотрим на [[id:379E4CAD-A44B-4631-8DAF-F3DC708EAEDE][Усиленное неравенство для функций с липшицевым градиентом]].
Из него мы знаем, что
\[
f(y) \le f(x) + \left\langle \nabla f(x); y-x \right\rangle + \frac{L}{2} \| y-x \|^2
\]
Давайте возьмем $y:= x- \alpha \nabla f(x)$ -- точка, куда мы шагнули и $\alpha$ -- шаг, который мы получили.
Тогда неравенство будет иметь вид
\[
f(x - \alpha \nabla f(x)) \le f(x) + \left\langle \nabla f(x); x - \alpha \nabla f(x) - x \right\rangle + \frac{L}{2} \| x - \alpha \nabla f(x)-x \|^2
\]
Что равносильно
\begin{multline*}
f(x - \alpha \nabla f(x)) \le f(x) - \alpha \left\langle \nabla f(x); \nabla f(x) \right\rangle + \frac{L}{2} \|  \alpha \nabla f(x)\|^2 = \\
= f(x) - \left( \alpha - \frac{L\alpha^2}{2} \right) \| \nabla f(x)\|^2 = f(x) - \alpha \left( 1 - \frac{L\alpha}{2}  \right) \| \nabla f(x)\|^2
\end{multline*}

Зададим $\phi(\alpha) = f(x - \alpha \nabla f(x))$. Тогда [[id:15611E05-13FC-4FB0-AE00-A4BB857A29E6][условие Армихо]] для $\alpha_0 = 0$, $\alpha_k = \alpha$:
\[
\phi(\alpha) < \phi(\alpha_0) + c_{1}(\alpha - \alpha_0) \cdot \phi^{\prime}(\alpha_0)
\]
Подставим значения $f$
\[
f(x - \alpha \nabla f(x)) <  f(x - 0 \cdot \nabla f(x)) - c_1 \alpha \| \nabla f(x) \|^2
\]
Пользуемся тем, что
\[
 \phi^{\prime}(\alpha) =  f^{\prime}(x - \alpha\nabla f(x))(- \alpha \nabla f(x))^{\prime}_{\alpha} =  - f^{\prime}(x - \alpha\nabla f(x)) \nabla f(x) =
 - (\nabla f(x - \alpha \nabla f(x)))^T \nabla f(x)
\]
Тогда $\phi^{\prime}(\alpha_0) = \phi^{\prime}(0) = - (\nabla f(x))^T \nabla f(x) = - \|\nabla f(x)\|^2$

Следовательно (при $\nabla f(x) \ne 0$) условие будет выполняться при $1 - \frac{L\alpha}{2} > c_{1} \Leftrightarrow \alpha < 2 \frac{1-c_1}{L}$
Заметим, что предыдущий $\alpha$ мы отвергли, следовательно шаг в $\frac{1}{\beta}$ раз больший $\alpha$ не подходит;

Итого
\[\alpha \ge \min \left\{ \alpha_0; \frac{2\beta(1-c_1)}{L} \right\}\]

То есть $\alpha$ это шаг порядка $\frac{1}{L}$.

*** Front
Метопт. Как работает backtracking для подбора шага и почему он останавливается?
*** Back
Начать с \(\alpha_0\); пока нарушено условие Армихо \(\phi(\alpha) \gt \phi(0) + c_1\alpha\phi'(0)\), умножать \(\alpha\) на \(\beta \in (0;1)\). Останавливается, так как Армихо выполнено на всём \((0;\delta)\), а \(\beta^k\alpha_0 \to 0\).

*** Text
Метопт. Backtracking для \(f \in C^{1,1}_L\), \(d = -\nabla f(x)\): условие Армихо выполнено при \(\alpha \lt\) {{c1::\(2(1 - c_1)/L\)}}, поэтому найденный шаг \(\alpha \ge\) {{c2::\(\min\{\alpha_0;\ 2\beta(1 - c_1)/L\}\)}} — порядка \(1/L\).
*** Back Extra
Из усиленного неравенства \(f(x - \alpha\nabla f(x)) \le f(x) - \alpha(1 - L\alpha/2)\|\nabla f(x)\|^2\); предыдущий шаг \(\alpha/\beta\) был отвергнут.
