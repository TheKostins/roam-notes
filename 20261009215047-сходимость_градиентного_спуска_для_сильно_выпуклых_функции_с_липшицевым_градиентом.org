#+title: Сходимость градиентного спуска для сильно выпуклых функций с липшицевым градиентом
#+filetags: :metopt:theorem:

Пусть $f: \R^n \to \R$, $f \in C^{1,1}_L$ ([[id:7DD1C7AB-1A49-4675-9F21-5A16C717F670][Функции с липшицевым градиентом]]), $\mu$-[[id:22E546FC-186F-4A67-85AA-2C85DCEF9021][сильно выпуклая]], $x^{*}$ -- её точка минимума (она [[id:51CC880D-BF19-43E2-9599-FB31A9A7367F][существует и единственна]]).
[[id:BEEE81AD-13FC-4846-A160-C72E31760BEE][Градиентный спуск]] с шагом $\alpha_k = \frac{1}{L}$: $x_{k+1} = x_k - \frac{1}{L} \nabla f(x_k)$.

Тогда $x_k \rightarrow x^{*}$, причем
\[
\| x_k -x^{*}\|^2 \le \left( 1 - \frac{\mu}{L} \right)^k \|x_0 -x^{*}\|^2
\]

* Доказательство
По [[id:FFEA1F1D-B70C-4B4A-9386-8344A2A3BBC4][оценке убывания за шаг]] при $\alpha = \frac{1}{L}$ для любого $y$ имеем $f\left(y - \frac{1}{L}\nabla f(y)\right) \le f(y) - \frac{1}{2L}\|\nabla f(y)\|^2$, а слева стоит значение $f$, не меньшее минимума $f(x^{*})$. Значит
\[
\frac{1}{2L}\| \nabla f(y)\|^2 \le f(y) - f(x^{*})
\]
(то же следует из [[id:655064DF-D686-4726-83DC-6F3D67CC5B9C][оценки для выпуклых функций с липшицевым градиентом]] при $x := x^{*}$ -- так в конспекте.)

Из [[id:1B5A3E25-56E8-4D5E-9CF6-E2731DA77604][дифференциального критерия сильной выпуклости]] следует, что
\[
f(y) \ge f(x) + \left\langle \nabla f(x); y-x \right\rangle + \frac{\mu}{2} \|y-x\|^2
\]

Пусть $x_{k+1} = x_k -\alpha \nabla f(x_k)$, где $\alpha = \frac{1}{L}$ (пока не подставляем).

Тогда
\[
\| x_{k+1} - x^{*}\|^2 = \|x_k - x^{*} - \alpha \nabla f(x_k)\|^2
= \|x_k - x^{*}\|^2 - 2 \left\langle x_k - x^{*}; \alpha \nabla f(x_k) \right\rangle + \| \alpha \nabla f(x_k)\|^2
\]


Заметим, что
\[
f(y) \ge f(x) + \left\langle \nabla f(x); y-x \right\rangle + \frac{\mu}{2} \|y-x\|^2 \Leftrightarrow -
\left\langle \nabla f(x); y-x \right\rangle \ge f(x) - f(y) + \frac{\mu}{2} \|y-x\|^2
\]
Применим это для $y:=x^{*}, x:=x_{k}$.
\[
-\left\langle \nabla f(x_k); x^{*}-x_k \right\rangle \ge f(x_k) - f(x^*) + \frac{\mu}{2} \|x_k-x^*\|^2
\]
Тогда давайте занесем минус в скалярное произведение
\[
\left\langle \nabla f(x_k); x_k - x^{*} \right\rangle \ge f(x_k) - f(x^*) + \frac{\mu}{2} \|x_k-x^*\|^2
\]
Домножим все неравенство на $-1$
\[
- \left\langle \nabla f(x_k); x_k - x^{*} \right\rangle \le  f(x^*) - f(x_k) - \frac{\mu}{2} \|x_k-x^*\|^2
\]



Также заметим, что
\[
\| \alpha \nabla f(x_k)\|^2 = \frac{1}{L^2} \| \nabla f(x_k)\|^2
\]
По неравенству из спуска
\[
\frac{1}{L^2} \| \nabla f(x_k)\|^2   = \frac{2}{L} \cdot \frac{1}{2L} \| \nabla f(x_k)\|^2
\le \frac{2}{L} (f(x_k) - f(x^{*}))
\]

Далее давайте применим эти оценки к $\|x_{k+1} - x^{*}\|^2$
\begin{multline*}
\| x_{k+1} - x^{*}\|^2 = \|x_k - x^{*} - \alpha \nabla f(x_k)\|^2
= \|x_k - x^{*}\|^2 - 2 \left\langle x_k - x^{*}; \alpha \nabla f(x_k) \right\rangle + \| \alpha \nabla f(x_k)\|^2 \\
\le \|x_k - x^{*}\|^2 + 2\alpha \left( f(x^{*}) - f(x_k) - \frac{\mu}{2} \|x_k - x^{*}\|^2\right)
+ \frac{2}{L} (f(x_k) - f(x^{*}))
\end{multline*}

Заменим $\alpha = \frac{1}{L}$ и сгруппируем слагаемые.
\begin{multline*}
\|x_k - x^{*}\|^2 + \frac{2}{L} \left( f(x^{*}) - f(x_k) - \frac{\mu}{2} \|x_k - x^{*}\|^2\right) + \frac{2}{L} (f(x_k) - f(x^{*})) = \\
\| x_k - x^{*}\|^2 \left( 1 - \frac{\mu}{L} \right) + \frac{2}{L} (f(x^{*}) - f(x_k) + f(x_k) - f(x^{*})) = \| x_k - x^{*}\|^2 \left( 1 - \frac{\mu}{L} \right)
\end{multline*}

Итого получили, что
\[
\| x_{k+1} - x^{*}\|^2 \le \|x_k - x^{*}\|^2 \left( 1- \frac{\mu}{L} \right) \le \ ... \le
\|x_0 - x^{*}\|^2 \left( 1- \frac{\mu}{L} \right)^{k+1}
\]

Так как $\mu \le L$ ([[id:3C6CF60E-0773-488E-A0B9-4D7510D456C0][связь сильной выпуклости и липшицевости градиента]]), $0 \le 1 - \frac{\mu}{L} < 1$, и правая часть стремится к нулю: $x_k \to x^{*}$.

Получили [[id:DF2405BF-8B31-47EB-8DEF-B1A88034717C][линейную сходимость]] для [[id:C42D2C19-B35F-4C0E-AFEB-D880CBB72176][невязки]] $\|x_{k} - x^{*}\|^2$: $C = \|x_0- x^{*}\|^2$, $q = 1 -\frac{\mu}{L}$ (для самой $\|x_k - x^{*}\|$ знаменатель $q = \sqrt{1 - \mu/L}$).

/Rem/: Без сильной выпуклости ([[id:C3B64D64-D35B-42AC-B683-6736227CBBBC][теорема для $C^{1,1}_L$]]) есть лишь сублинейная оценка $c/\sqrt{k}$ для нормы градиента; сильная выпуклость даёт линейную сходимость самих точек со знаменателем $1 - \mu/L = 1 - 1/\kappa$, где $\kappa = L/\mu$ -- число обусловленности.

*** Front
Метопт. Сходимость ГС для \(\mu\)-сильно выпуклой \(f \in C^{1,1}_L\) с шагом \(1/L\): что утверждается?
*** Back
\(x_k \to x^{*}\), причём \(\|x_k - x^{*}\|^2 \le (1 - \mu/L)^k \|x_0 - x^{*}\|^2\) — линейная сходимость.

*** Front
Метопт. Идея доказательства сходимости ГС для сильно выпуклых функций (шаг \(1/L\)).
*** Back
Раскрыть \(\|x_{k+1} - x^{*}\|^2 = \|x_k - x^{*}\|^2 - 2\alpha\langle\nabla f(x_k); x_k - x^{*}\rangle + \alpha^2\|\nabla f(x_k)\|^2\); скалярное произведение оценить через сильную выпуклость, норму градиента — через \(\frac{1}{2L}\|\nabla f\|^2 \le f(x_k) - f^{*}\); при \(\alpha = 1/L\) слагаемые с \(f\) сокращаются.

*** Front
Метопт. Какие два неравенства используются в доказательстве сходимости ГС для сильно выпуклых функций?
*** Back
1) \(\frac{1}{2L}\|\nabla f(y)\|^2 \le f(y) - f(x^{*})\) — оценка убывания за шаг при \(\alpha = 1/L\) плюс \(f(y - \frac{1}{L}\nabla f(y)) \ge f(x^{*})\) (или теорема 2.5 при \(x = x^{*}\)); 2) \(f(y) \ge f(x) + \langle\nabla f(x); y - x\rangle + \frac{\mu}{2}\|y - x\|^2\) — дифференциальный критерий сильной выпуклости.

*** Front
Метопт. ГС для сильно выпуклой \(f\): с какими \(C, q\) линейно сходится невязка \(\|x_k - x^{*}\|^2\), и почему \(q \lt 1\)?

\(C = \|x_0 - x^{*}\|^2\), \(q = 1 - \mu/L \in [0;1)\), так как \(\mu \le L\). Для \(\|x_k - x^{*}\|\) знаменатель \(\sqrt{1 - \mu/L}\).
