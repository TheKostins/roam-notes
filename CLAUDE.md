# Vault org-roam: правила для агента

Личный vault org-roam (университетская математика, сейчас курс `metopt`). Язык заметок и общения — **русский**. Заметки атомарные: одна заметка = одно определение / теорема / метод. Человек пишет заметки в Emacs; агент проверяет их, собирает lecture-заметки и готовит Anki-карточки.

## Жёсткие правила

1. **Ни одной правки `.org` без одобренного номера находки / карточки / черновика.** Сначала отчёт в чат, потом ждать ответа («применить 1,3,5-8»), потом править только выбранное. Исключений нет, даже для опечаток.
2. Не трогать: `:ID:`, свойства `ANKI_*`, поддеревья `* Review` и `* Anki` (последнее — только в рамках `/notes-anki`).
3. Не использовать тег `review` и слово «review» для проверки агентом: это занято интервальным повторением заметок (`my/roam-review`, `C-c n r`). Процесс агента называется **проверка / audit**.
4. Не переписывать описания ссылок: `[[id:…][выпуклых множеств]]` склоняется намеренно и не обязано совпадать с заголовком.
5. Не раскрывать макросы (`\R`, `\conv`, …) в теле заметок — там они разрешены. В карточках Anki — наоборот, только раскрытые.
6. Перед записью в заметку: `python3 tools/roam.py guard <ref> --expect-hash <file_hash>` (хэш из `show`/`context`). Отказ → перечитать файл, не перезаписывать.
7. Коммиты — только в точках, описанных в скиллах (snapshot до, apply после). Никаких `git push`, rebase, amend.
8. PDF-конспект прошлого года — источник *структуры* и перекрёстной сверки, **не авторитет**: он местами неясен и может отличаться от лекций этого года. Расхождение ≠ ошибка.

## Контракт формата заметки

```org
:PROPERTIES:
:ID:       316B5BFA-8B9F-4267-9086-D6593AAB5F9B
:END:
#+title: Выпуклое множество
#+filetags: :metopt:definition:

Формулировка: проза + $inline$ и
\[
display
\]

* Доказательство
* Пример
```

- **Header**: drawer только с `:ID:` (UUID в верхнем регистре) → `#+title:` → `#+filetags:` подряд, без пустых строк между ними; опционально `#+date:` (lecture). Имя файла `YYYYMMDDHHMMSS-<slug>.org` — создавать только через `roam.py new` (slug как у org-roam: й→и, ё→е).
- **Теги**: сначала курс (`metopt`, `calc` — реестр в `roam.toml`), затем тип (`definition`, `theorem`, `lemma`, `example`, `method`, `property`). Workflow-теги (`backfill`, `lecture`, `hub`, `image`, `review`) могут стоять где угодно. Порядок важен: `my/anki-deck-for-buffer` берёт деку из первого не-workflow тега.
- **Заглушка**: тег `:backfill:` + тело `backfill` — понятие, на которое уже ссылаются, но оно ещё не написано.
- **Математика**: inline `$…$`; display `\[` и `\]` на отдельных строках; окружения (`gather`, `align`) — самостоятельно, не внутри `\[ \]`. Правила границ Org для `$`: сразу после открывающего и перед закрывающим `$` нет пробела; после закрывающего — пробел, пунктуация, дефис или конец строки (не буква). Слова внутри формул — только в `\text{…}` (не `\texttt`, не `\mathrm` с кириллицей). Штрих — `'` или `^{\prime}`.
- **Макросы**: из `my/notes-latex-macros` (`roam.py macros`). Новая команда вне списка → либо опечатка, либо добавить в `tools/known_macros.txt`.
- **Ссылки**: только `[[id:UUID][свободное описание]]`. Внешние материалы — обычные `[[file:…][…]]` / `[[https:…][…]]`.
- **Заголовки**: `* Доказательство`, `* Пример`, вложенные шаги доказательства. Заголовки без `:ID:` (все узлы — file-level).
- **Экспорт-безопасность** (будущий HTML): никакого сырого HTML/LaTeX вне формул; всё служебное (карточки, Review) — под `:noexport:`; картинки — относительные ссылки в `images/`.

### Lecture-заметка

Теги `:lecture:<курс>:`, `#+date: YYYY-MM-DD`, заголовок «Метопт. Лекция N: тема». Разделы: `* Материалы`, `* План лекции`, `* Вне конспекта`, `* Открытые вопросы`. В lecture-заметке (и только в ней) описания ссылок = заголовки заметок в именительном падеже. Содержание не пересказывается — только структура.

### Anki-поддерево (в конце concept-заметки)

```org
* Anki :noexport:
:PROPERTIES:
:ANKI_DECK: Notes::metopt
:END:
** Выпуклое множество: определение
:PROPERTIES:
:ANKI_NOTE_TYPE: Basic
:END:
*** Front
Метопт. Когда множество \(C \subset V\) называется выпуклым?
*** Back
Если \(\forall x, y \in C\ \ \forall \lambda \in [0;1]\):
\[ \lambda x + (1-\lambda) y \in C \]
```

Поля — подзаголовки с точными именами полей Anki (`roam.toml [anki.*]`; сверены с профилем: `Basic` — `Front`/`Back`, `Cloze` — `Text`/`Back Extra`), всегда все поля явно. `ANKI_DECK` — в drawer родителя `* Anki` (не `#+property:` — тот кэшируется в открытом буфере). В карточках: `\(…\)` / `\[…\]` вместо `$`, макросы раскрыты, `\lt`/`\gt` вместо `<`/`>`, без id-ссылок, в Cloze не допускать `}}` внутри формулы (писать `} }`). После push anki-editor сам дописывает `ANKI_NOTE_ID` / `ANKI_NOTE_HASH` — это не меняет body-hash заметки.

## Тулинг: `python3 tools/roam.py <cmd>`

Источник правды — файлы, не sqlite-база org-roam. `<ref>` = UUID / префикс UUID / имя файла / заголовок (или его уникальная часть).

| Команда | Зачем |
|---|---|
| `pending` | что нового / изменилось с последней проверки; заглушки отдельно |
| `list [--tag T] [--since YYYYMMDD] [--until …] [--status …] [--json]` | инвентарь; окно по времени создания |
| `show <ref>` / `context <ref> [--full-linked]` | тело с номерами строк + хэши / полный бандл для проверки |
| `lint [<ref>…] [--rules 'M*,T02'] [--json]` | детерминированные проверки (H/T/K/M/X/A/C); без ref — весь vault |
| `fix <ref>… [--rules …] [--apply]` | механика H04, H06, T02, X02; по умолчанию dry-run с diff |
| `spell [<ref>…]` | кандидаты hunspell (термины вроде «подграфик», «Минковского» — ложные) |
| `mentions <ref>` | упоминания заметки без ссылки |
| `new --title T --tags a,b [--date D] [--body-file F\|-] [--dry-run]` | создать заметку |
| `macros [--json\|--mathjax]`, `expand [--card]` | макросы конфига; раскрытие (stdin→stdout) |
| `cards [<ref>…] [-v] [--check] [--stale]` | карточки, A-правила, устаревшие карточки |
| `guard <ref>… [--expect-hash H]` | проверка перед записью: хэш файла + несохранённые буферы Emacs (через `emacsclient`) |
| `sync` | `org-roam-db-sync` в запущенном Emacs |
| `state mark\|cards\|dismiss\|show …` | `.audit/state.json` |
| `pdfmap <курс>`, `grep-pdf <курс> <regex>` | «Пара N → страницы», поиск по конспекту |

`pdftotext` искажает формулы — им только искать; содержание страницы читать через Read с `pages` (физические номера).
Тесты: `python3 -m unittest tools/test_roam.py`.

## Процессы (скиллы)

- `/notes-audit` — проверка новых/изменённых заметок: отчёт → выборочное применение.
- `/notes-lecture` — собрать lecture-заметку по конспекту и заметкам.
- `/notes-anki` — карточки из проверенных заметок.

Порядок работы над лекцией: заметки → `/notes-audit` → `/notes-lecture` → `/notes-anki`.

## Emacs: что важно знать

- `global-auto-revert-mode` включён, lock-файлов нет: чистые буферы подхватят правки сами; буфер с несохранёнными изменениями — риск конфликта. В Emacs запущен сервер (`server-start` в `my-core.el`), поэтому `guard` сам видит несохранённые буферы vault и отказывает; если сервер недоступен — попросить сохранить буферы (`C-x s`).
- База org-roam не видит внешние правки и новые файлы: после сессии — `python3 tools/roam.py sync` (если сервер недоступен, напомнить `M-x org-roam-db-sync`).
- Карточки отправляет пользователь из Emacs при запущенном Anki (AnkiConnect): `C-c n a` — карточки текущей заметки, `C-c n P` — всех заметок с карточками. Агент сам в Anki ничего не пишет; читать AnkiConnect (`modelFieldNames`, `findNotes`) можно.
- `theme-*.org` — сгенерированные сборки (`C-c n T`), в git не попадают, тулингом игнорируются.
- Конфиг: `~/.config/emacs/lisp/my-org.el` (репозиторий `~/dotfiles2`). Менять его — только по отдельной явной просьбе.
