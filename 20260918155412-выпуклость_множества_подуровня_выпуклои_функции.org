#+title: Выпуклость множества подуровня выпуклой функции
#+filetags: :metopt:theorem:

Пусть $f: E \rightarrow \R$ -- [[id:1CA14F2C-637F-41DE-9E97-72075D19E97F][выпуклая функция]], $c \in \R$, $E$ -- [[id:316B5BFA-8B9F-4267-9086-D6593AAB5F9B][выпуклое]]
Тогда $\mathrm{Lev}_f(c) = \left\{ x \in E \  |\  f(x) \le c  \right\}$ -- [[id:316B5BFA-8B9F-4267-9086-D6593AAB5F9B][выпуклое множество]]

* Доказательство
Будем проверять определение выпуклого множества.

Возьмем произвольные $x, y \in \mathrm{Lev}_f(c), \lambda \in [0;1]$.
Заметим, что $\mathrm{Lev}_f(c) \subset E \Rightarrow x,y \in E$
Знаем, что $\lambda x + (1-\lambda) y \in E$ [[id:316B5BFA-8B9F-4267-9086-D6593AAB5F9B][(по выпуклости)]]

По выпуклости $f$: $f(\lambda x + (1-\lambda)y) \le \lambda f(x) + (1-\lambda)f(y)$

\[
x,y \in \mathrm{Lev}_f(c) \Rightarrow \lambda f(x) + (1-\lambda)f(y) \le \lambda c + (1-\lambda)c = c
\]

Но тогда, $f(\lambda x + (1-\lambda)y) \le c \Rightarrow (\lambda x + (1-\lambda)y) \in \mathrm{Lev}_{f}(c)$
Итого $\mathrm{Lev}_f(c)$ -- выпуклое [[id:316B5BFA-8B9F-4267-9086-D6593AAB5F9B][по определению]].

*** Back

*** Front
Метопт. Почему \(\mathrm{Lev}_f(c) = \{ f \le c \}\) выпукло для выпуклой \(f\)?
*** Back
\(x, y \in \mathrm{Lev}_f(c)\): \(f(\lambda x + (1-\lambda) y) \le \lambda f(x) + (1-\lambda) f(y) \le \lambda c + (1-\lambda) c = c\).
